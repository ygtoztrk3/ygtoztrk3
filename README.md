.NET developer. I build web applications for real clients, mostly with ASP.NET Core, Entity Framework Core and SQL Server.

I also build workflow automations with n8n, which I self-host on RepoCloud.

### Stack

C#, ASP.NET Core MVC, Web API, Entity Framework Core, LINQ, SQL Server, JWT, ASP.NET Identity, Serilog, Git, n8n

### Projects

- GatePass – event and ticket reservation system with three user roles
- Misya Cave Hotel – hotel website with online reservations, Turkish and English

- SitePanel – a central admin panel to manage multiple websites from one place
- Luci – a personal voice assistant
- EkipOzturk – a multi-agent software team built with .NET and the Claude API
